        使用说明

        导入曲谱

        • MusicXML（.musicxml / .xml）：MuseScore、西贝柳斯、Overture 等软件都能导出，这是五线谱的通用交换格式。
        • ABC 记谱（.abc / .txt）：纯文本记谱法，AI 生成也用它。

        连接钢琴

        • 需要 Chrome / Edge 浏览器，通过 http://127.0.0.1:8321 访问（Web Bluetooth 安全要求）。
        • 点击「连接钢琴」，在弹窗中选择你的琴（名称以 MP / POP Keyboard / PianoProdigy / GPP / Xkey 开头）。
        • 协议已按泡泡钢琴 App 逆向：服务 03B80E5A-…，特征 7772E5DB-…，连接后自动发送控制权握手。
        • 测试时请先断开手机 App 与琴的连接，琴的 BLE 同一时间一般只接受一个连接。

        练琴

        • 播放时曲谱上的音符会实时高亮；速度 50%~150% 可调，可循环。
        • 连接钢琴后勾选「琴发声」，播放的音符由钢琴音源演奏；勾选「跟灯」会在琴键上点亮当前音。
        • 节拍器仅对 MusicXML 曲谱生效（ABC 使用自带合成器）。

        跟弹练习（三大模式核心）

        • 等待模式：不播放、不限时。琴键上蓝灯亮哪里就弹哪里，弹对熄灭跳下一组；弹错那颗键闪红灯提示。适合初学抠谱。
        • 跟弹评分：手机播放曲谱（可开跟灯引导），你跟着一起弹；每个音判定命中/漏弹/错音，练完给出正确率与平均反应延迟。适合提速与完整度训练。
        • 声部筛选：选「右手」只考核右手旋律，左手自由伴奏不计错；「左手」反之。适合分手练。
        • 错音即时红灯反馈；和弦要按齐所有音才算过。练习记录自动保存在本机，可追踪正确率变化。
        • 速度滑杆对两种模式都生效：等待模式控制的是「跟弹评分」的播放速度，等待模式本身不限速。

        曲库批量导入

        • 「导入文件」支持一次多选：.abc / .txt（ABC 记谱）、.musicxml / .xml、.mxl（MuseScore 压缩格式）、.mid / .midi（自动转成可练的谱面）。
        • MIDI 转 ABC 按 1/16 音符量化，节奏自由的 MIDI 转换后可能需要微调速度。
        • 免费正版曲谱来源（公有领域/开放授权，可批量下载后再导入）：
          • Mutopia Project — 公有领域古典曲，GitHub 仓库可整包 clone；
          • The Session — 上万首传统曲调 ABC，带 JSON API 可批量拉取；
          • IMSLP — 公有领域乐谱图书馆（多为 PDF 扫描，少数 MusicXML）；
          • MuseScore.com — 社区谱面，筛选「公有领域」后下载 .mxl 直接导入；
          • BitMidi 等免费 MIDI 站 — 配合本应用的 MIDI 导入转谱。
        • 注意版权：受版权保护的流行歌曲请勿批量分发，自用练习请遵守来源站点的授权条款。

        AI 写谱

        • 「离线算法生成」完全本地运行，按风格/调性/难度随机作曲，适合每天练新的。
        • 「大模型写谱」调用你自己的 OpenAI 兼容接口；浏览器直连失败时会自动走本地代理（serve.py）。
